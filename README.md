# MalayPrag: Overview

This project introduces a dataset and evaluation framework for assessing whether LLMs can interpret the pragmatic functions of Colloquial Malay discourse particles, focusing on the particles `kan` and `ke`, as well as null-form baselines derived from particle removal.

The dataset is designed to support evaluation of pragmatic attributes such as epistemic stance, listener agreement, affect, question type, and particle position. These attributes are further used to derive broader pragmatic function labels.
